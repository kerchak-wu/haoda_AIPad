好搭AI派资料库

## 项目内容

### 音乐播放器

基于 `pygame-ce` 开发的桌面音乐播放器，固定窗口尺寸 1920×1080，支持播放本地音乐文件、进度拖动、音量调节等功能。

- **主程序**：`music_player.py`
- **背景图**：`images/1.jpg`
- **音乐目录**：`recordings/`（放入 mp3/wav/ogg/flac 格式文件即可自动加载）

#### 快捷键

| 按键 | 功能 |
| --- | --- |
| `空格` | 播放 / 暂停 |
| `←` / `→` | 上一首 / 下一首 |
| `↑` / `↓` | 音量 + / 音量 - |
| `ESC` | 退出程序 |

#### 运行方式

```bash
pip install pygame-ce
python3 music_player.py
```

详细说明见 [音乐播放器项目文档.md](音乐播放器项目文档.md)。
