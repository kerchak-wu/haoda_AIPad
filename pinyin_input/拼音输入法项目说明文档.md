# 拼音输入法 项目说明文档

## 一、项目概述

离线拼音输入应用：屏幕软键盘（鼠标点选）+ USB 键盘双通道打字，词组优先、字频兜底的候选排序，支持首字母简拼和可选模糊音；「按住说话」语音输入（云端识别）；内置手机辅助页——手机浏览器打开设备局域网地址即可打字一键推送。**既可以独立运行，也可以作为组件被其他 pygame 程序调用。**

- 主程序：`拼音输入法.py`（独立应用）
- 核心库：`pinyin_engine.py`（离线拼音引擎，无 UI 依赖）
- 组件库：`input_panel.py`（可嵌入 pygame 输入面板）
- 服务库：`phone_bridge.py`（手机辅助页 HTTP 服务，纯标准库）
- 语音库：`voice_input.py`（录音 + 云端识别封装，无 UI 依赖）
- 维护工具：`构建拼音词典.py`（重建词典数据）
- 词典数据：`data/pinyin_dict.json`（约 9.4MB，须随程序一起部署）
- **部署位置：`/home/cxdz/jupyter/user/pinyin_input/`（英文子文件夹，不散落在 user 根目录）**
  - 程序启动时自动 `chdir` 到自身所在文件夹：`data/ logs/ recordings/` 全部生成在子文件夹内，与 user 根目录隔离；
  - 从任何位置启动（管理器或 SSH）都能正确定位资源；
  - SSH 启动：`cd /home/cxdz/jupyter/user/pinyin_input && DISPLAY=:0 python3 拼音输入法.py`（管理器可启动子文件夹程序，已实测 2026-11-17）；
- 日志：`pinyin_input/logs/拼音输入法_YYYYMMDD.log`（追加模式）
- 窗口：**1280×820** 非全屏（用户 2026-11-17 指定：先压到 780，后为容纳更大按键调整到 820，覆盖界面规范默认值）

## 二、使用方法（独立运行）

1. 在设备上新建 `/home/cxdz/jupyter/user/pinyin_input/` 文件夹（**目录名必须用英文**），将 `拼音输入法.py`、`pinyin_engine.py`、`input_panel.py`、`phone_bridge.py`、`voice_input.py`、`构建拼音词典.py` 与 `data/` 文件夹放进去（整文件夹复制即可）；
2. 凭据保存在设备 `pinyin_input/credentials.py`（`USERNAME / PASSWORD` 两个常量，**该文件只存在于设备，不属于仓库**，重新部署 .py 时无需重传）；代码读取优先级：构造参数 > 环境变量 > credentials.py > 代码内常量（留空）；
3. 运行 `拼音输入法.py`（SSH 下 `cd /home/cxdz/jupyter/user/pinyin_input && DISPLAY=:0 python3 拼音输入法.py`，或经管理器启动）；
4. **面板三页结构**（点面板顶部标签切换，编辑区三页共用，**三页均可使用 USB 键盘输入**，语音/手机页打拼音时底部出现轻量候选条：两端 ◀/▶ 翻页、每页最多 9 个、页码显示在 ▶ 左侧、点词即上屏；当前拼音串显示在编辑区右上角小字）：
   - **键盘页**：软键盘点选，或 USB 物理键盘打全拼；候选栏 **◀ 在最左、▶ 在最右**（大三角形按钮），每页 9 个、候选池 **90 个（10 页，覆盖生僻字）**，数字键按当前页序号选词，页码 x/y 显示在 ▶ 左侧；
   - **语音页**：仅两个同尺寸方形按钮——**提交（绿，左）+ 按住说话（红，右）**，底边对齐、间距加大；
   - **手机页**：仅大二维码（约 300px，左）+ 地址说明（**顶边与二维码对齐**，中）+ **提交矩形 240×130（右）**，底边对齐；**双向实时同步**：打开手机页及未编辑时每 1.5 秒自动拉取设备编辑区内容；点「发送到设备」= **覆盖**设备编辑区（手机框内本就含设备全文，因此只更新增量，不会重复）——用户在手机上编辑过则暂停自动拉取，发送后恢复；
   - 键盘布局：第三行 中/EN + 字母 + **回车**（行尾）；第四行 **符号**（空格左边）| 空格 | **清空** | **退格** | 提交；
   - 候选词选择：按 **数字键 1~9** 或点选候选词上屏；**PageUp/PageDown** 在三页均可前后翻页（与 ◀/▶ 按钮等效）；**空格**选第一个候选；**退格**先删拼音字母、删完再删已上屏文字；**回车**把原始字母上屏；**中/EN** 切换（英文模式直接上屏，Shift 大写）；中文模式 `.,?!;:()` 自动映射全角；
   - **符号** 键打开符号面板（**自动跟随当前语言**：中文模式进中文全角页、英文模式进英文半角页，「更多」互换、「字母」返回），点选即插入；
5. **提交按钮**：绿色，三页均有；点击取出编辑区全部文字（复制到剪贴板，如可用）并清空，宿主程序通过 `panel.on_submit_cb` / `panel.take_text()` 接收；
6. 右上角红色「退出」按钮或键盘 ESC 退出（顶栏仅 标题 + 退出）。

## 三、被其他程序调用的方法

组件部署在 `/home/cxdz/jupyter/user/pinyin_input/`，其他程序（无论在 user 根目录还是别的子文件夹）调用前，**先把该文件夹加入 `sys.path`**。建议相对宿主程序文件位置解析（已在 人脸学习.py 落地，管理器/SSH 两种启动方式都正确）：

```python
import os, sys
_PI_DIR = os.path.join(os.path.dirname(os.path.abspath(__file__)), 'pinyin_input')
if os.path.isdir(_PI_DIR) and _PI_DIR not in sys.path:
    sys.path.append(_PI_DIR)
```

之后按需选择三种形态：

```python
# 形态一：无头调用（只要候选词，不要界面，适用于语音对话纠错等场景）
from pinyin_engine import PinyinIME
ime = PinyinIME()                     # 可传 fuzzy=True 开启模糊音
ime.push_keys('nihao')
ime.candidates()                      # ['你好', ...]
ime.choose(0)                         # 选中并自学习；ime.committed_text 累积上屏文本
ime.commit_external('语音识别结果')    # 外部文本直接进编辑区

# 形态二：嵌入现有 pygame 程序（在宿主 display/font 初始化之后）
from input_panel import PinyinInputPanel
panel = PinyinInputPanel(
    pygame.Rect(60, 420, 1160, 600),
    font_path='/home/cxdz/jupyter/assets/msyh.ttc',
    on_commit=my_callback,            # 每次上屏一词回调
    voice_press=start_record,         # 语音按钮按下（可接 voice_input）
    voice_release=stop_record,
    english_only=False,               # True=英文锁定模式（见下）
)
# english_only=True 英文锁定模式（2026-11-18 新增）：
#   - 强制英文模式且禁止中/EN 切回，标签行仅保留键盘页（语音/手机页隐藏）
#   - 符号面板固定英文半角页，无候选翻页键
#   - append_text/set_text/take_text 均过滤为可打印 ASCII（汉字/全角符号拦在入口）
#   - 适用场景：宿主输入框只接受英文/数字（如人脸学习姓名、物体学习类名）
# 宿主主循环里：
panel.handle_event(event)             # True 表示事件被面板消费
panel.draw(screen)
panel.text                            # 随时读取完整编辑内容
text = panel.take_text()              # 提交：取出全部文本并清空编辑区
panel.on_submit_cb = do_submit        # 「提交」按钮回调（面板各页功能行最右的绿键）
panel.page = 'voice'                  # 可直接指定页面（'kb'/'voice'/'phone'）
panel.voice_status = '状态文字'        # 语音页状态（宿主可写）
panel.phone_status = '已收到: xxx'     # 手机页状态（宿主可写）

# 形态三：手机页当外接输入台（可独立于界面使用）
from phone_bridge import PhoneBridge
bridge = PhoneBridge()                # 端口每次启动系统随机分配，无固定端口
bridge.start()
print(bridge.url)                     # start() 后才有值，显示给用户
# 宿主主循环里每帧轮询：
text = bridge.get_text()              # 取到手机推送文本（取走即清空），None 表示无新文本
bridge.stop()                         # 退出前调用
```

语音输入单独调用（宿主自建界面时）：

```python
from voice_input import VoiceInput
vi = VoiceInput()                     # 凭据从设备 credentials.py 或环境变量读取
if vi.is_available():
    vi.start_record()                 # 按下时调用
    text = vi.stop_and_recognize()    # 松开时在子线程调用，返回识别文本或 ''
```

路径规则（文件调用保证）：
- `pinyin_engine` 的词典路径基于**自身文件位置**定位（`pinyin_input/data/pinyin_dict.json`），宿主无需切换工作目录；
- `input_panel` 不读写文件，只依赖宿主已初始化的 pygame display/font；
- `voice_input` 的录音临时文件默认落**宿主当前工作目录**的 `recordings/` 下；嵌入宿主可在运行时重定向模块属性 `voice_input.RECORDINGS_DIR`（人脸学习.py 已重定向到 `pinyin_input/recordings/`，避免散落 user 根目录）；
- `phone_bridge` 不读写文件，随机端口天然支持局域网多台设备同时使用，不会串。

**嵌入宿主实测案例（2026-11-17 真机验收通过：人脸学习.py、物体学习.py；2026-11-18 起两宿主切换 `english_only=True` 英文锁定模式并真机验收通过）**：点击姓名/名称框弹出模态面板（尺寸与独立程序一致 1160×666，位置左右居中、底边贴窗口底边 `Rect(380,414,1160,666)`），`panel.handle_event(event)` 返回 True 时宿主跳过处理（防点击穿透）；提交走 `take_text()` 一键形态（`panel.on_submit_cb` 回调），编辑区有字回填输入框、为空清空输入框；打开面板时 `panel.set_text()` 回填输入框已有文字供修改；语音回调接 `panel.voice_press_cb/voice_release_cb`，手机推送轮询仅在面板打开时进行（英文锁定模式下语音/手机页隐藏、入口不可达，回调接线保留不影响）。集成代码见《人脸学习项目说明文档.md》第九章第 8 节、《物体学习项目说明文档.md》第九章第 8 节。

## 四、技术实现

| 环节 | 实现 | 说明 |
|---|---|---|
| 离线引擎 | `pinyin_engine.PinyinIME` | 纯标准库；音节 DP 切分 + 有序 key 二分前缀匹配；词组（完整匹配）> 简拼 > 扩展长词 分层降权 |
| 词典数据 | `data/pinyin_dict.json`（9.4MB，26 万音节键、34.6 万候选） | 由 `构建拼音词典.py` 合并三个开源数据源生成：jieba dict.txt（简体词频，MIT）+ mozillazg/phrase-pinyin-data（词组拼音）+ mozillazg/pinyin-data（单字多音，次读音降权 1/20） |
| 简拼 | 加载时构建首字母索引（全库频次 Top3 万多音节词） | `nh`→你好、`zg`→中国 |
| 模糊音 | `PinyinIME(fuzzy=True)` | zh/z、ch/c、sh/s、n/l、an/ang、en/eng、in/ing，声母韵母分别映射 |
| 自学习 | `data/pinyin_user_freq.json` | 选词/外部上屏即计数，用户词频加权 50000，退出时与每次选词后落盘 |
| 录音 | `audio_recorder.AudioRecorder`（16kHz/1ch/float32） | 按下 `start_recording()`，松开 `stop_recording()` + `save_audio()` 落盘 |
| 语音识别 | `voice_api.voice_recognition(文件路径)` | 失败/401 时自动 `get_token` 重登再试一次；凭据仅存设备副本 |
| 手机辅助页 | `phone_bridge.PhoneBridge` | 标准库 `http.server.ThreadingHTTPServer` 后台线程；端口**每次启动由系统随机分配**（无固定端口选项，多设备不冲突）；手机页浅色移动端单页，Ctrl+Enter 也可发送；`get_text()` 取走即清空；可选 PIN |
| 字体 | 正文 `/home/cxdz/jupyter/assets/`（PingFang/msyh 逐个回退）；标题楷体 `simkai.ttf`（等线/雅黑兜底，用户 2026-11-17 指定更换） | `input_panel.load_font()` 统一加载，Windows 字体兜底便于本地调试 |
| 二维码 | `qrcode` + PIL 10.4.0 → `pygame.image.frombuffer` | 设备已实测可用；生成失败时仅显示文字地址 |
| 初始化 | `pygame.display.init() + pygame.font.init()` 分段初始化 | 无摄像头、无 mixer，规避 V4L2 与音频子系统风险 |

## 五、界面设计

- **1280×820** 非全屏窗口（用户指定调整），浅色天空蓝主题（面板 #EAF4FB / 强调蓝 #2E9BE6 / 语音按钮红 #EB5757 方形 / 提交按钮绿 #22A05A）；所有按键带立体感（底部投影 + 顶边高光，按下下沉）；
- 顶栏：楷体标题「拼音输入法」+ 右上角红色「退出」；标题与面板间距压缩；
- 面板三页共用编辑区（白底圆角、多行、光标闪烁、按行高裁剪可见行数）+ 标签行（键盘/语音/手机）：
  - 键盘页：候选栏（词槽 9 个 + **◀ 大三角在最左、▶ 在最右** + 页码 x/y）→ 软键盘（QWERTY 三排，第三行行尾「回车」）→ 功能行（符号/空格/退格/清空/提交）；
  - 语音页：状态文字 → **提交（绿）+ 按住说话（红）** 两个同尺寸方形按钮，底边对齐；
  - 手机页：大二维码（约 300px，左）+ 地址与说明（中）→ **提交大方形（右）**，底边对齐；
- 录音中语音按钮变深红、文字变「松开」。

## 六、已知限制 / 坑

1. **整句连续输入不支持**：引擎按「词组+字」候选设计，一次输入超过 4~5 个音节且无法成词时返回空候选——请按词输入（日常打字习惯即如此）；
2. **简拼排序无上下文模型**：`nh` 的第一个候选可能是「南海」而非「你好」（按通用词频排序）；多打几个字母即可纠正，自学习会逐渐偏向个人习惯；
3. **多音字罕用读法已降权**（1/20），但极个别词组仍可能因单字拼音兜底拼合出现误读音（词库直配拼音的 4.3 万词组不受影响）；
4. 语音识别需外网与凭据；凭据保存在**设备** `pinyin_input/credentials.py`（不属于仓库；重新部署 .py 无需重传该文件），仓库与本地文档禁止写入凭据；
5. 手机辅助页端口每次启动由系统随机分配（**无固定端口**，局域网内多台设备同时运行也不会串），二维码与文字地址均显示在顶部；启动失败时程序提示但不影响拼音/语音功能；
6. 手机页不做网页端语音识别（浏览器 Web Speech API 支持不一），语音统一走设备端；
7. 词典重建需三个数据源文件（下载地址见 `构建拼音词典.py` 头部注释），设备上一般**直接随程序部署现成的 `data/pinyin_dict.json` 即可**；
8. 本程序无摄像头，与摄像头类程序可独立运行（注意管理器中先停止其他程序再运行）；
9. **USB 物理键盘必须系统先识别**：2026-11-17 实测诊断，键盘无反应时 `lsusb` 中无任何 USB 设备——先检查右下角两位开关是否拨到**左侧**（启用外设）、换扩展板另一个 USB 母口并重插；系统识别后（`lsusb` / `xinput list` 可见）程序自动生效，无需改代码；
10. 符号面板模式下 USB 键盘仅保留退格/空格/回车，符号插入以屏幕点选为主。
