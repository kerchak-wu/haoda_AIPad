## 6. 日志不完整怎么办

1. **缺某一节**：先看该节有没有 `$ 命令` 输出。若只是 `pip list` / `dmesg` / `v4l2-ctl` 被权限或未安装挡住，属正常，如实标注即可。
2. **整份缺失 / 程序中途崩**：重新跑一次
   ```bash
   # 把 探测工具/探测_待定项核对.py 复制到设备 /home/cxdz/jupyter/user/ 后：
   cd /home/cxdz/jupyter/user && PYTHONPATH=/home/cxdz/jupyter/lib python3 探测_待定项核对.py
   ```
   （约 1~3 分钟；日志落在 `logs/探测_待定项核对_YYYYMMDD_HHMMSS.log`）
3. **F 节报 `v3_runtime` 异常**：把 traceback 摘要写进决议记录，**F 节其余 KEY 视为未知**（不要用推测值填空）。
4. **想省时间**：把 `探测_待定项核对.py` 里的 `_TEST_AUDIO_RECORD` 改为 `False` 可跳过 I 节的 2 秒录音测试；其余节不要跳。
